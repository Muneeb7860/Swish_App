# SandboxLogs

Monospace log/code output viewer with syntax highlighting and scrolling.

## Features
- Monospace font (Fira Code)
- Dark background for contrast
- Horizontal/vertical scrolling
- Line height optimized for readability
- Thin custom scrollbar

## Styling
- Background: root dark
- Border: subtle
- Font: Fira Code 10px
- Text color: secondary for logs

## Use Cases
- Test output display
- Error log viewers
- API response display
- Code preview/demo output
- Debug information display
