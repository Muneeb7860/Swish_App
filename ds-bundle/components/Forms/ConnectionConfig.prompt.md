# ConnectionConfig

Form component for entering connection configuration parameters.

## Features
- Input fields (`.input-field`) with focus states
- Select dropdowns (`.select-field`) with custom styling
- Labeled form groups
- Focus ring (indigo glow)
- Placeholder text in muted color
- Full-width responsive layout

## Styling
- Input background: root dark
- Border: default (subtle white)
- Focus: indigo border + glow background
- Text: primary on dark

## Use Cases
- API connection settings
- Database configuration
- Service endpoint setup
- Connection parameter forms

## Accessibility
- Proper label associations
- Focus-visible outlines
- Semantic form structure
