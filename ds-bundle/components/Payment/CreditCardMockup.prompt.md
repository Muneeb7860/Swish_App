# CreditCardMockup

Premium 3D credit card visualization with holographic effects and shimmer animations.

## Props
None — this is a pure presentational component.

## Behavior
- Displays a styled credit card mockup (320×190px)
- Hologram rectangle with shimmer animation
- Gold chip with inset border
- 3D hover effect with tilt and glow
- Glass morphism background

## Use Cases
- Payment method display
- Checkout UI visual
- Premium UI showcase
- Onboarding illustration

## Styling Notes
Uses Tailwind utilities + CSS custom properties:
- `.premium-credit-card` — main container with gradient background
- `.premium-credit-card-hologram` — animated hologram effect
- `.premium-credit-card-chip` — gold chip with inset shadow
- Hover: 3D transform (translateY, rotateX, rotateY) + glow
